# 轻量课程表 Android 应用 — 需求与设计文档

> 版本：v1.0 · 2026-09-05  
> 目标平台：Android 12 (API 31) 及以上，`targetSdk 34`，纯离线、秒开、轻量  
> 技术栈：Kotlin + Jetpack Compose (Material3) + Room + DataStore + Glance AppWidget  
> 源码目录：`D:\Me\My Project\课程表`

---

## 1. 概述

### 1.1 产品定位
一款**极简、轻量、无登录、纯离线**的大学生/中学生课程表。核心价值：
- **自由时间框架**：每节课有独立的 `startTime/endTime`（分钟级），不绑定“第几节”的固定时间段。
- **按周视图 + 按学期统览**：日为列、时间为行，横向 7 列（周一~周日），纵向时间轴（用户自定义范围，如 07:00-22:00），课程块按实际时间比例渲染。
- **阶段（Phase）模型**：同一课程名下可含多个阶段，每个阶段有独立的 `星期 + 时间 + 重复规则 + 教师/教室/备注`。同名即同课，便于统计与着色一致。
- **非本周灰显**：当周不上但学期内其他周上的课，同位置浅色显示并前缀“非本周”。
- **桌面小部件**：显示“今日+明日”课程，已结束课程自动隐藏，支持拉伸自适应。

### 1.2 设计原则
- **轻量秒开**：冷启动 <800ms，无网络请求，无臃肿依赖。首屏仅加载当前周。
- **离线优先**：所有数据本地 `Room SQLite`，支持 `JSON` 完整备份/恢复（首选），`CSV` 表格导出（可选二期）。
- **单 APK <15MB**，无后台常驻，仅 Widget 的 `WorkManager` 周期刷新（30min）。

## 2. 功能需求

### 2.1 学期管理 (Semester)
| 字段 | 类型 | 说明 |
|------|------|------|
| id | Long PK | 自增 |
| name | String | 如 “2026春” |
| startMonday | LocalDate | 学期第1周周一日期（用户手动设置） |
| totalWeeks | Int | 如 20，周数 |
| displayStartMin | Int | 视图时间轴起点（分钟，如 420=07:00），用户指定 |
| displayEndMin | Int | 终点（如 1320=22:00） |
| isCurrent | Boolean | 当前学期 |

- 交互：首次启动引导创建学期；设置页可新增/切换/编辑/删除学期；删除学期级联删除其课程阶段。
- 周推算：`weekIndex = ceil((date - startMonday).days /7)+1`，1-indexed，周一为周首。

### 2.2 课程与阶段 (CoursePhase)
> **关键约定**：`courseName` 相同即视为同一门课（统计、着色、总览均按此归组）。创建课程时，输入课程名支持下拉自动补全已有的课名，选择后即为该课的新阶段；默认继承同名课程最近阶段的 `teacher/classroom/color`，可改。

- **CoursePhase 字段**
  - `id: Long PK`
  - `semesterId: Long FK`
  - `courseName: String`（归组键）
  - `color: Int ARGB`（预设 12 色中选其一，同名课程所有阶段同色，改色则同名全改）
  - `dayOfWeek: Int 1..7`（1=周一）
  - `startMin/endMin: Int`（0..1439，分钟级，如 480=08:00，结束>开始，允许跨半小时）
  - `teacher: String?`
  - `classroom: String?`
  - `note: String?`
  - `repeatType: Enum { EVERY_WEEK, ODD_WEEK, EVEN_WEEK, INTERVAL }`
  - `intervalWeeks: Int`（仅 INTERVAL 时生效，如 2=隔周，3=每3周）
  - `startWeek: Int`（该阶段首次出现的周次，1..totalWeeks）
  - `endCondition: Enum { UNTIL_WEEK, REPEAT_COUNT }`
  - `endWeek: Int?`（UNTIL_WEEK 时）
  - `repeatCount: Int?`（REPEAT_COUNT 时，如 8 次）

- **预设 12 基础色**：Material  tonal palette，满足区分度且不过艳
  ```
  #4A90E2 蓝, #50C878 翠绿, #FF6B6B 珊瑚红, #FFD93D 明黄, #9B59B6 紫, #1ABC9C 青绿
  #FF8A65 橙, #64B5F6 浅蓝, #81C784 浅绿, #E57373 浅红, #BA68C8 浅紫, #FFB74D 浅橙
  ```
  提供 `colorId 0..11` 映射，浅色（非本周）= 原色 `alpha 0.35 + desaturate`。

- **重复规则展开算法**（见 §4.3）：
  - `EVERY_WEEK`：`startWeek..endWeekOrCount` 每周出现
  - `ODD/EVEN`：在范围内仅奇/偶周出现（以学期第1周为基准 weekNumber%2）
  - `INTERVAL`：`occurrenceWeeks = { startWeek + k*interval | k>=0 }` 再按 `UNTIL_WEEK` 或 `REPEAT_COUNT` 截断
  - 判定“某课程阶段在 Week N 是否出现”用于周视图渲染与 Widget。

### 2.3 周视图 (Week View) — 主屏
- **布局**：`docs/week_view_mock.png`（文字描述）
  - 顶部 `TopBar`：居中显示“第 N 周”（仅周次，无日期），左右箭头/`HorizontalPager` 左右滑动切换周（`swipe` + 按钮），支持快速跳周下拉（可选）。
  - 标题行下方：7 列头 `周一..周日 (M/d)`，如 `周一 9/8`，日期由 `startMonday + (weekIndex-1)*7 + (day-1)` 推算。
  - 主体：左侧时间轴刻度 `60分钟一格`（如 07:00,08:00..），右侧 7 列网格，每列为一天的时间纵轴。网格高度 = `(displayEndMin-displayStartMin)/60 * hourHeight`（`hourHeight=64dp`）。
  - 课程块：绝对定位，`top = (startMin-displayStartMin)/60*hourHeight`，`height = (endMin-startMin)/60*hourHeight`，不占满格则按比例高度，圆角 8dp，显示课程名 + 教室（若空间足够显示教师）。
  - 非本周课程：同位置渲染但 `alpha 0.35`、前置文案“非本周 ”，字体灰色。提供设置开关“隐藏非本周”（默认显示）。
  - 冲突叠放：同一天同一时间重叠的课程块**层叠**，下层露出 `8dp` 右/下边缘以示多张卡；**单击**该叠放区域切换 `zIndex`（轮转置顶），点击非重叠区域弹详情。
- **交互**：
  - 单击非冲突课程 → `BottomSheet` 详情：课程名、颜色、教师/教室/备注、该阶段的重复规则文案（如“每周 周三 08:00-10:00 1-16周”），提供“编辑此阶段 / 删除此阶段 / 删除整门课”。
  - 长按任意空白或课程块 → 进入“添加/编辑”页（若长按课程则预填为编辑）。
  - 空白处长按 → 新建课程，自动带入 `dayOfWeek` 与 `startMin`（根据长按 Y 坐标推算最近半小时）。
- **性能**：仅计算当前周的可见阶段（`semester.totalWeeks <= 25`，数据量 <500 条），主线程无 DB 阻塞，用 `collectAsState`。

### 2.4 添加/编辑课程页
- 表单字段：
  1. 课程名 `TextField` + `ExposedDropdownMenu`（已有的 `distinct courseName` 列表，选后即为新阶段，自动填充同名课程的 `color/teacher/classroom`）。
  2. 颜色选择器：12 色横向 `Chip`，单选，同名课程联动改色（提示“将同步更新该课程所有阶段”）。
  3. 星期 `SegmentedButton 1..7`
  4. 时间 `TimePicker`（开始/结束，分钟级，校验结束>开始且在 display 范围内可超出但提示）。
  5. 教师、教室、备注 `TextField`（可选）。
  6. 重复规则区：
     - 类型：`每周 / 单周 / 双周 / 间隔N周`（间隔时显示 `N` 输入 1..8）
     - 起始周：`NumberPicker 1..totalWeeks`
     - 结束条件：`Radio` “截止到第 X 周” vs “重复 N 次”（二选一），对应输入 `endWeek` 或 `repeatCount`。
     - 实时预览文案：如“每2周 周四 10:00-12:00 从第1周起 共8次 → 1,3,5,7,9,11,13,15周”。
  7. 底部保存；若编辑已有阶段，提供“重命名即脱离原课程”提示（改名后该阶段独立为新课程名，颜色独立）。
- 校验：结束时间>开始、重复次数/截止周合法、interval>=1、endWeek>=startWeek。

### 2.5 学期总览 (Semester Overview)
- 入口：主屏 `TopBar` “总览”按钮或抽屉。
- 展示：按 `courseName` 去重的**课程列表**（不显示具体时间），每行显示 `色块 + 课程名 + 阶段数 + 教师（首阶段）`。
- 点击某课程 → 二级页列出该课程的所有阶段卡片，每卡显示：星期时间、重复规则文案、教室/教师、备注。支持在此页对单阶段编辑/删除。
- 排序：按课程名字典序或创建时间。

### 2.6 桌面小工具 Widget (Glance)
- 尺寸：单一 `GlanceAppWidget`，声明 `minWidth 180dp, minHeight 110dp`，支持**自由拉伸**（`resizeMode horizontal|vertical`），内容自适应。
- 内容：
  - 标题 “今日 / 明日” 分区（若今日已无课则仅显示明日）。
  - 每分区列出课程按 `startMin` 排序，已结束的今日课程**不显示**（`endMin < nowMin` 过滤）。
  - 每行：`色块 + 时间 HH:mm-HH:mm + 课程名 + 教室`，非本周课程同样灰显 + “非本周”。
  - 底部显示当前学期与周次 “2026春 · 第3周”。
  - 空态：显示“今日无课 / 明日无课”。
- 交互：点击 Widget 任意位置 → 启动主 Activity 定位到当日所在周；点击单条（若 RemoteViews 支持）→ 同上。
- 刷新：`WorkManager 30min` + `onReceive ACTION_TIME_TICK` + 应用内数据变更后 `GlanceAppWidgetManager.updateAll()`。

### 2.7 导入导出
- **首选 JSON**（私有完整格式，最方便）：
  ```json
  {
    "exportVersion": 1,
    "exportedAt": "2026-09-05T12:00:00",
    "semesters": [{ "name":"2026春", "startMonday":"2026-02-16", "totalWeeks":20, "displayStartMin":480, "displayEndMin":1320 }],
    "phases": [{ "semesterName":"2026春", "courseName":"高数", "colorIndex":0, "dayOfWeek":3, "startMin":480, "endMin":600, "teacher":"张三", "classroom":"A101", "repeatType":"EVERY_WEEK", "startWeek":1, "endCondition":"UNTIL_WEEK", "endWeek":16 }]
  }
  ```
  通过系统 `SAF` 文件选择器 `CreateDocument/ OpenDocument` 实现，无需存储权限（Android 12+）。
- **CSV**（可选二期）：每行一阶段，便于 Excel 编辑，字段同上。
- **ICS** 暂不实现（日历导入会丢失重复规则中的单双周语义），如需可作为二期。

### 2.8 其他
- 设置页：学期管理、时间轴范围调整、是否隐藏非本周、备份/恢复、关于。
- 删除：提供“删除此阶段”与“删除整门课（所有同名阶段）”二次确认对话框。
- 冲突：允许保存重叠课程，不阻塞。

## 4. 数据与算法

### 4.1 ER 图
```
Semester 1 ──* CoursePhase
CoursePhase 归组键 courseName (逻辑归组，非外键)
```

### 4.2 关键判定
```kotlin
fun isPhaseActiveInWeek(phase: CoursePhase, week: Int): Boolean {
  val weeks = expandWeeks(phase) // 按 repeatType+endCondition 展开
  return week in weeks
}
fun expandWeeks(p: CoursePhase): Set<Int> {
  val result = mutableSetOf<Int>()
  var w = p.startWeek
  var count = 0
  val maxWeek = if (p.endCondition == UNTIL_WEEK) p.endWeek!! else Int.MAX_VALUE
  val maxCount = if (p.endCondition == REPEAT_COUNT) p.repeatCount!! else Int.MAX_VALUE
  while (w <= maxWeek && count < maxCount && w <= semester.totalWeeks) {
    when (p.repeatType) {
      EVERY_WEEK -> { result.add(w); w += 1; count += 1 }
      ODD_WEEK, EVEN_WEEK -> {
        val isOdd = w % 2 == 1
        val wantOdd = p.repeatType == ODD_WEEK
        if (isOdd == wantOdd) { result.add(w); count += 1 }
        w += 1
      }
      INTERVAL -> { result.add(w); count += 1; w += p.intervalWeeks }
    }
  }
  return result
}
// 单双周的“奇偶”以学期第1周为第1周（奇）为基准
```

### 4.3 非本周判定
对某 `week`，对某时间槽 `(day, startMin-endMin)` 若存在某 `phase` 在该槽但 `!isActive(week)`，则该槽仍渲染该课程的块但置灰。

> 注意：若同一课程名下多阶段在同一时间槽，仅需判断“是否存在至少一个活跃阶段”，活跃的正常色，非活跃的才灰显。实现时按 `courseName` 分组后取活跃/非活跃两类。

## 5. UI 设计规范

- **Material3**，`ColorScheme` 使用 12 基础色作为课程强调色，背景 `surface`。
- **排版**：标题 `titleMedium`，课程块内 `labelSmall`（课程名粗体）+ `bodySmall`（教室）。
- **手势**：周切换 `HorizontalPager`，页数 = `totalWeeks`，`rememberPagerState` 双向绑定 `currentWeek`。
- **空态与边界**：学期未创建 → 引导页；当周无课 → 插画 + “本周无课”；时间轴超出 `displayEndMin` 的课程仍可保存但视图中需纵向滚动或提示“超出显示范围”。

## 10. 风险与对策

- **时间重叠计算性能**：周视图每次展开全学期阶段 → 缓存 `Map<week, List<Phase>>`，仅当前周计算。
- **Widget 刷新频率**：Glance 限制 → 采用 `WorkManager 30min` + 应用内主动刷新，避免过度耗电。
- **SAF 兼容性**：部分定制 ROM 文件选择器异常 → 降级到 `ActivityResultContracts.CreateDocument` 并提示。
